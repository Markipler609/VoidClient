01 — Capabilities

Built like a launch site then,
a launcher like no other.

◆/01

A background that breathes

Bayer-dithered cells drift and bloom live on a GL shader — the same one running behind this page. Click anywhere.

★/02

Stupid fast

Launches, downloads and dependency resolution run in parallel. Median boot is well under a second.

✉/03

Real Microsoft auth

Sign in once with a device code, play online with your skin and cape. Offline mode is one toggle away.

⚕/04

Mods, the easy way

Search, filter and install mods per version right from the launcher. Whatever loader you run.

☰/05

Every version, grouped

Releases, snapshots, old betas and alphas are sorted into clean groups — from Alpha 1.0 to 1.21.4.

✿/06

Glass everywhere

Frosted panels, a floating pill nav and a single-white-accent palette. Custom UI effects, tints and presets included.
