01 — What you need

Minimal kit, per platform.

◑Windows

Windows 10 / 11 · x64

About the shortest path to a launcher:

  • Node.js 20 LTS — nodejs.org
  • npm — ships with Node
  • Git — git-scm.com
  • Java 21+ — adoptium.net, needed to play
  • Discord desktop — for Rich Presence

No Visual Studio, no build tools. `npm install` is the whole setup.

★Linux

Any modern distro · x64

Same tooling as Windows, plus Electron's deps:

  • Node.js 20 LTS + npm
  • Git
  • Java 21+ — to play
  • Electron libs — libnss3, libgtk-3-0, libasound2
  • Discord desktop — for Rich Presence

On Debian/Ubuntu: sudo apt install libnss3 libgtk-3-0 libasound2.

02 — Build it

Clone, install, run.

  1. Clone the repository

    Everything lives in one repo — the Electron launcher in `mc-launcher/`, this website in `website/`.

    git clone https://github.com/Markipler609/VoidClient.git
  2. Install dependencies

    Only production dependencies are packaged. Works on Windows and Linux unchanged.

    cd VoidClient
cd mc-launcher
npm install
  3. Run in dev mode

    Electron launches straight from source — live reload, full logs in `~/.voidclient/logs/`.

    npm start
  4. Build releases

    Electron Builder produces the installers. Output lands in `dist/`.

    npm run build          // current platform
npx electron-builder --win --linux   // or pick targets
  5. Wire Discord Rich Presence

    Replace the placeholder client ID in `src/discord-rpc.js` (or set `VOID_DISCORD_APP_ID`), then upload the launcher icon as the art asset `void_logo` in the Discord Developer Portal.

# Windows        dist/VOID CLIENT Setup 1.0.0.exe      + portable exe
# Linux          dist/void-client-1.0.0.tar.gz
